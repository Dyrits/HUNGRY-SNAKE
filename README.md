# Hungry Snake

A Java implementation of the classic Snake game, built for the CodeGym game task "Hungry Snake".

![Snake](https://cdn.codegym.cc/images/system/22e7f1ba-8b1a-41b3-a483-58134b68c361/original.jpeg)

## About The Project

The original README noted that this project was made from scratch following the task's specific instructions, with several elements (such as the game engine) provided by the course.

The original README's changelog:

- V1.01: colors modified; grid extended to 20x20; a special "Slow Apple" added, reducing the game's speed.
- V1.02: the Slow Apple renamed "Slow Green Apple", with a different unicode character.
- V1.03: pressing a direction key no longer removes the dialog message at the end of a game.


The original task description from CodeGym is preserved in [ASSIGNMENT.md](ASSIGNMENT.md).
